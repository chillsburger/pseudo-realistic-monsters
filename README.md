# Pseudo-Realistic Monsters

Static pitch website for Bobby Abate's feature film. Uses supplied stills from the proof-of-concept short, The Ghost at Skeleton Rock.

## Run locally

From this directory, run `python3 -m http.server 8000` and visit http://localhost:8000.

## GitHub Pages

Publish the repository's `main` branch, root directory, in Settings → Pages. All asset links are relative and support a repository-based Pages URL. No build process or third-party dependencies are required.

## Edit

Website copy is in `index.html`; appearance is in `styles.css`; photographs are the `.jpg` files in the root directory. Contact: bobby@sweetkitty.com.
